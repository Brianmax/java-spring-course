Una compra de Ana

Un pedido registra lo que una persona quiere comprar. Ana quiere 3 cuadernos de S/ 12 cada uno.

Calcular el total del pedido

Objetivo: relacionar cantidad × precio unitario con el total de una compra.

Los datos de Ana

3 cuadernos

S/ 12 por cuaderno

3 × S/ 12 = S/ 36

La cantidad cuenta unidades; el precio indica cuánto cuesta una unidad.

Fragmento dentro de main

int cantidad = 3;
double precio = 12;
double total = cantidad * precio;
System.out.println(total); // 36.0

El resultado representa S/ 36.
