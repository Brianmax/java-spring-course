# Introducción a Java · G19

Ejemplos y ejercicios de la primera semana del curso, organizados por tema. El proyecto usa Java 21 y está preparado como módulo sencillo de IntelliJ IDEA; no requiere Maven ni Gradle.

## Abrir el proyecto

1. Descarga el ZIP desde la página del proyecto y descomprímelo. Contiene solo este proyecto.
2. Abre la carpeta `java-g19-intro` en IntelliJ IDEA. Incluye el módulo `javag19_semana1.iml`.
3. Instala o selecciona un JDK 21 en la configuración del proyecto.
4. Dentro de `src`, elige una clase que tenga `main` y ejecútala con el botón junto al método.

## Contenido

- `src/variables/`: variables y ejercicios de entrada, operaciones y datos.
- `src/condicionales/`: comparaciones, operadores lógicos y decisiones.
- `src/arrays/`: arrays y operaciones básicas de `ArrayList`.
- `src/loops/`: bucles y ejercicios de repetición.

Los archivos `.class` generados al compilar se excluyen del proyecto; IntelliJ puede volver a generarlos al ejecutar el código.
