Cómo empezar

Instala y arranca MySQL Server 8 o posterior. En MySQL Workbench, abre tienda.sql y ejecuta todo el archivo una sola vez. Luego abre consultas.sql y ejecuta sus consultas. La base tienda debe estar libre: el script no borra ni sobrescribe una base existente. Consulta el README completo para el esquema, comandos de terminal y resultados esperados.
