Reporte de notas

Un profesor necesita registrar las notas de su salón y obtener un resumen. Construye un programa de consola en Java que le permita ingresar los datos y consultar los resultados.

Lo que vas a practicar

Combina lectura con Scanner, arrays, bucles for y while, condicionales, contadores y acumuladores para resolver un problema completo.

Requisitos del programa

  1. Pide la cantidad de estudiantes: debe ser un número entero entre 1 y 30, ambos incluidos. Si está fuera del rango, muestra un mensaje y vuelve a pedirlo.
  2. Registra una nota por estudiante: cada nota debe ser un entero entre 0 y 20, ambos incluidos. Guarda las notas en un array. Si una nota es inválida, pide nuevamente la del mismo estudiante; no avances al siguiente.
  3. Calcula y muestra el resumen: promedio del salón con decimales, nota mayor, nota menor, cantidad de aprobados y cantidad de desaprobados. Se aprueba con una nota de 11 o más.
  4. Muestra quiénes superan el promedio: indica el número y la nota de cada estudiante con una nota estrictamente mayor que el promedio. Numera a los estudiantes desde el 1 y conserva el orden de registro. Si ninguno lo supera, muestra “Ningún estudiante supera el promedio”.

Puedes asumir que el usuario siempre escribe números enteros. Debes validar sus rangos; no se requiere manejar letras ni otros formatos de entrada. Compara las notas con el promedio sin redondearlo.

Ejemplo de funcionamiento

El usuario registra 5 estudiantes e ingresa, en este orden, las notas 15, 8, 20, 11, 6. El reporte debe contener:

Promedio del salón: 12.0
Nota mayor: 20
Nota menor: 6
Aprobados: 3
Desaprobados: 2
Estudiantes por encima del promedio:
Estudiante 1: 15
Estudiante 3: 20

Los textos y el formato pueden variar, pero los resultados y las reglas deben coincidir.

Condiciones de entrega

  • Crea el archivo ReporteNotas.java con la clase ReporteNotas y resuelve el ejercicio dentro de main.
  • Usa Scanner, un array para guardar las notas, al menos un for, al menos un while y condicionales.
  • Calcula los resultados recorriendo los datos. No uses streams ni funciones de biblioteca para obtener la suma, el promedio, el máximo o el mínimo.
  • Entrega tu archivo Java y evidencia de ejecución de los casos de prueba siguientes, como texto o capturas de consola.

Comprueba tu solución

  • Un estudiante con nota 11: promedio 11.0, mayor y menor 11, un aprobado, ningún desaprobado y nadie por encima del promedio.
  • Tres estudiantes con notas 14, 14, 14: promedio 14.0, tres aprobados y nadie por encima del promedio.
  • Cuatro estudiantes con notas 0, 20, 10, 11: promedio 10.25, mayor 20, menor 0, dos aprobados y dos desaprobados. Los estudiantes 2 y 4 superan el promedio.
  • Entradas inválidas: ingresa 0 y 31 como cantidad de estudiantes antes de ingresar 2. Luego ingresa −1 y 21 antes de registrar la primera nota válida. El programa debe repetir cada solicitud sin contar ni guardar los valores inválidos.

Antes de entregar, comprueba que el total de aprobados y desaprobados sea igual a la cantidad de estudiantes y que todos los bucles terminen.

Preguntas para guiarte

  • ¿Qué bucle conviene cuando conoces la cantidad de repeticiones? ¿Cuál sirve para insistir hasta recibir un valor válido?
  • ¿Qué variables cuentan estudiantes y cuál acumula las notas?
  • ¿Con qué valor puedes iniciar el máximo y el mínimo para que funcionen con cualquier conjunto de notas válidas?
  • ¿Cómo evitas perder los decimales al calcular el promedio?
  • ¿En qué momento ya conoces el promedio y puedes recorrer las notas para compararlas con él?

Desafío opcional: tres notas por estudiante

Amplía el programa para leer tres notas enteras entre 0 y 20 por estudiante. Usa bucles anidados y guarda el promedio de cada estudiante en un array de double.

Genera el mismo reporte usando esos promedios: promedio del salón, mayor y menor promedio individual, aprobados con promedio de al menos 11 y estudiantes que superan el promedio del salón. No redondees los valores antes de compararlos.
