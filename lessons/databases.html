Un gestor concreto

¿Quién recupera A-17?

MySQL Server es el software gestor en ejecución: recibe solicitudes, comprueba el acceso y lee o escribe datos.

El programa servidor no es la base de datos: tienda es el conjunto de datos almacenados que administra.

Si MySQL Server se detiene o reinicia, las filas ya guardadas no se borran por eso; mientras esté apagado, Java no puede consultarlas.

Evitar una confusión

¿Cerrar Workbench apaga MySQL?

No: MySQL Workbench es una aplicación cliente, no MySQL Server ni la base de datos tienda.

Si se detiene MySQL Server, Workbench y Java pierden acceso; los datos ya guardados no se borran por apagarlo. Instalar Workbench no garantiza que el servidor esté instalado o iniciado.

Del vínculo a la consulta

¿Cómo encontrar a Ana desde A-17?

Consulta SQL de ejemplo · tablas Clientes y Pedidos de tienda
SELECT p.id, c.nombre
FROM Pedidos AS p
JOIN Clientes AS c
  ON p.cliente_id = c.id
WHERE p.id = 'A-17';
Coincidencia

Pedido A-17 → cliente_id C-01
Cliente C-01 → Ana

Resultado
A-17 · Ana

El modelo relacional organiza los datos; SQL es un lenguaje para consultarlos en muchos gestores. Esta consulta no es código Java.

Una opción no relacional

Un documento por producto

“No relacional” nombra una familia de modelos. En uno de ellos, el de documentos, cada producto agrupa sus datos propios. Estos dos ejemplos tienen IDs estables.

Estos objetos están escritos en formato JSON como ejemplo de datos. “No relacional” es una familia de modelos, no un lenguaje de consulta único.
