10 · Preparación · JDK 21

El editor no reemplaza al kit de desarrollo.

Instala y selecciona un JDK

JDK significa kit de desarrollo de Java. Incluye javac, la JVM y bibliotecas estándar. Configura JDK 21 en tu IDE.

Un editor organiza archivos. Un IDE añade ejecución, depuración y herramientas de proyecto.

Comprueba la instalación

java --version
javac --version

Ambos comandos deben mostrar la versión 21. Si no se encuentran, revisa la instalación y PATH, las carpetas donde la terminal busca comandos.

Modelo: editor → código; compilador → bytecode; JVM → ejecución. No necesitas Spring para comenzar.

17 · Variables · actualizar

Al llegar un mensaje, se calcula y guarda el nuevo contador.

int mensajesSinLeer = 3;

System.out.println(mensajesSinLeer); // 4
De 3 a 4
  1. Lee el valor actual: 3.
  2. Suma 1: el resultado es 4.
  3. Guarda 4 con el mismo nombre.
¿Qué valor habría después de leer todos los mensajes?
El mismo nombre conserva el estado actual. La salida muestra 4.

21 · Decisiones

Una condición verdadera acepta el pedido; una falsa lo rechaza.

stock 3 ≥ cantidad 2 ?
true · verdaderoAceptar pedido
false · falsoRechazar pedido
int stock = 3;
int cantidad = 2;
if (stock >= cantidad) {
  System.out.println("Pedido aceptado");
} else {
  System.out.println("Pedido rechazado");
}
Regla: aceptar si el stock es al menos la cantidad solicitada. Predice qué cambia cuando stock pasa a 1.
22 · Decisiones · varios rangos

Con else if, se elige la primera regla verdadera.

Regla de tarifas de este ejemplo

Subtotal ≥ 100 → envío S/ 0

Si no, subtotal ≥ 50 → envío S/ 5

Si no → envío S/ 8

Con subtotal S/ 75, el envío es S/ 5.

double subtotal = 75.0;
double envio;
if (subtotal >= 100) {
  envio = 0;
} else if (subtotal >= 50) {
  envio = 5;
} else { envio = 8; }
Este ejemplo usa tres tarifas. La compra integrada más adelante tendrá una regla más simple. Java toma la primera rama que coincide.
23 · Decisiones · valor exacto

Cuando comparas un valor con opciones conocidas, switch organiza los casos.

Estado recibido

estado = "PAGADO"

¿Qué valor tiene estado?
PAGADOEnviar
NUEVORevisar
otro valorPendiente
String estado = "PAGADO";
switch (estado) {
  case "PAGADO" -> System.out.println("Enviar");
  case "NUEVO" -> System.out.println("Revisar");
  default -> System.out.println("Pendiente");
}
Se ejecuta el caso que coincide exactamente; default cubre los demás. Para rangos como «mayor o igual que», usa if. Esta forma funciona en Java 21.

27 · Arrays · límites

El tamaño no cambia y los índices válidos van de 0 a length - 1.

asistentes.length =3· índices válidos

El primer índice es 0; el último es 2 porque hay tres espacios.

int cantidad = asistentes.length;

29 · ArrayList · crear

import java.util.ArrayList;

asistentes.add("Mía");
asistentes.add("Noa");
Valores tras cada paso

Termina con cuatro textos. ArrayList<String> es una lista flexible de textos de la biblioteca estándar.

Cambios visibles

32 · Práctica guiada

Prueba las dos colecciones con los mismos asistentes.

  2. Agrega los tres nombres y Noa a lista; su tamaño será 4.

33 · Repetición

Saluda a Ana, Luis y Mía sin copiar la instrucción tres veces.

Posición 0 → comprobar: ¿i < 3?
Sí · repetirSaludar al asistente · incrementar i · volver a comprobar
No · terminarEn posición 3 ya no queda un asistente

Usa for

Cuando conoces el contador o la colección que vas a recorrer.

Usa while

Cuando la repetición depende de una condición que puede cambiar.

Detención: el contador pasa por 0, 1 y 2; al llegar a 3, termina antes de intentar otro saludo.
34 · Bucles · colección

for repite una acción para cada asistente.

String[] asistentes = {"Ana", "Luis", "Mía"};
for (int i = 0; i < asistentes.length; i++) {
  System.out.println(asistentes[i]);
}
Recorrido y salida

Ana · Luis · Mía

Inicia i en 0 → comprueba i < 3 → imprime → actualiza.

i++ incrementa i en uno. En i = 3, la condición es falsa y el bucle termina antes de acceder al array.

35 · Bucles · condición

while repite mientras su condición siga siendo verdadera.

Estado inicial

asistentes = [Ana, Luis, Mía] · índices 0, 1 y 2

String[] asistentes = {"Ana", "Luis", "Mía"};
int i = 0;
while (i < asistentes.length) {
  System.out.println(asistentes[i]);
  i++;
}
Mismo resultado

Se imprimen Ana, Luis y Mía.

i++ actualiza el índice. Cuando i vale 3, la condición es falsa y termina.

for reúne inicio, comprobación y actualización; while los deja visibles por separado.

Atención: sin actualizar i, el bucle podría no terminar.

La última comprobación evita consultar una posición que no existe.

String[] asistentes = {"Ana", "Luis", "Mía"};

38 · Aplicación

Calcula el total con un estado original y una regla clara.

Reglas: envío S/ 0 si el subtotal original es ≥ S/ 100; si no, S/ 8. Si la persona es miembro, descuenta 5% antes de sumar el envío.
double subtotalOriginal = 125.0;
boolean miembro = true;
double envio = 8.0;
if (subtotalOriginal >= 100) envio = 0;
double descuento = 0.0;
if (miembro) descuento = subtotalOriginal * 0.05;
double total = subtotalOriginal - descuento + envio;
System.out.println(total); // 118.75
Traza del estado
Iniciooriginal 125.0 · miembro true · envío 8.0
Envío125.0 ≥ 100 → 0.0
Descuento125.0 × 0.05 = 6.25
Total125.0 − 6.25 + 0.0 = 118.75
39 · Mentalidad de depuración

Un pequeño cambio puede explicar un resultado inesperado.

= vs ==

total = 100 guarda. total == 100 compara números.

División entera

5 / 2 con enteros produce 2, no 2.5.

Límite de una colección

Si hay 3 elementos, los índices válidos son 0, 1 y 2.

Comparar texto

== no compara las letras de dos textos. Usa "PAGADO".equals(estado) para comparar su contenido.

Depura así: predice el valor, ejecuta y compara el resultado.
