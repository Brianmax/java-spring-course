Preparación · JDK 21

El editor no reemplaza al kit de desarrollo.

Instala y selecciona un JDK

El JDK incluye javac, la JVM y las bibliotecas estándar. Configura JDK 21 en tu IDE.

Un editor organiza archivos. Un IDE añade ejecución, depuración y herramientas de proyecto.

Comprueba la instalación

Ambos comandos deben mostrar la versión 21. Si no se encuentran, revisa la instalación y la variable PATH.

09 · Implementación

Escribe un programa Java que imprima un mensaje en la consola.

public class Welcome {
  public static void main(
      String[] args) {
    System.out.println(
      "¡Bienvenido a Tecsup!");
  }
}
Léelo de arriba abajo
  1. Una clase agrupa el programa.
  2. main es el método de inicio.
  3. println imprime texto.
Característica de Java: sintaxis de clases, métodos y cadenas. El editor solo inicia el programa.
No pidas memorizar cada palabra clave todavía. El objetivo es identificar el punto de entrada y la salida observable.
Aplicación · tu primera ejecución

Del archivo a un mensaje visible.

Guarda como Welcome.java

El nombre coincide exactamente con la clase pública Welcome. Abre la terminal en esa carpeta.

javac -encoding UTF-8 Welcome.java
java Welcome

Resultado esperado

¡Bienvenido a Tecsup!

javac genera Welcome.class. java Welcome ejecuta la clase: no escribas .class en el comando.

Practica: cambia el mensaje, vuelve a compilar y ejecuta. Si el mensaje no cambia, ¿qué paso faltó?

11 · Variables

Declara primero el tipo; después asigna un valor a la variable.

int itemCount = 3;
double total = 149.90;
boolean paid = false;
String customer =
    "Ana";

Tipos iniciales comunes

int, double y boolean son primitivos. String es una clase que representa texto.

  • int — números enteros
  • double — cálculos decimales
  • boolean — verdadero o falso
  • String — texto
Nota sobre precisión: usa BigDecimal para cálculos monetarios de producción; double simplifica esta primera lección.
Variables · del valor inicial al nuevo estado

Asignar no es comparar: primero se calcula la derecha.

int stock = 3;
stock = stock - 1;
System.out.println(stock); // 2

final int LIMITE = 10;
// LIMITE = 12; no compila

Recorrido de la asignación

  1. Leer el valor actual: 3.
  2. Calcular 3 - 1: 2.
  3. Guardar 2 en stock.

final impide reasignar la variable. Las variables locales deben inicializarse antes de leerse.

Predice: después de stock = stock + 4;, ¿qué valor tiene? ¿Cambió también LIMITE?
12 · Mecánica

Los operadores transforman valores o los comparan.

Aritméticos

+ − * / %

subtotal + shipping
5 % 2 → residuo 1

Comparación

== != > < >= <=

Produce una respuesta booleana: verdadero o falso.

Lógicos

&& || !

&&: ambas verdaderas.
||: al menos una.
!: invierte el resultado.

double total = subtotal + shipping;
boolean eligible = total >= 100 && member;
boolean blocked = !eligible;
Léelo por su significado: «Elegible cuando el total es al menos 100 y el cliente es miembro».
13 · Decisiones

Un if permite que el programa elija un camino.

¿Hay unidades? stock > 0
↙ true · verdaderoConfirmar disponibilidad
↘ false · falsoInformar que no hay stock
if (stock > 0) {
  System.out.println("Disponible");
} else {
  System.out.println("Sin stock");
}
Regla: la condición debe ser una expresión booleana. Las llaves hacen visible cada camino y facilitan editarlo con seguridad.
14 · Decisiones

Elige la herramienta de decisión que corresponde a la pregunta.

Rangos y reglas compuestas
if (score >= 90) {
  grade = "A";
} else if (score >= 70) {
  grade = "C";
}

Supón que score es un entero y grade ya vale «Pendiente». Se toma solo la primera condición verdadera; si ninguna se cumple, no cambia.

Un valor, casos conocidos
switch (status) {
  case "PAID" ->
    System.out.println("Enviar");
  case "NEW" ->
    System.out.println("Revisar");
  default ->
    System.out.println("Pendiente");
}

Aquí status es un String. Las flechas ejecutan solo el caso elegido (Java 14+); usamos JDK 21.

15 · Repetición

Un bucle convierte una instrucción en una repetición controlada.

Inicio → comprobar condición
true · repetirCuerpo → actualización → volver a comprobar
false · terminarContinuar después del bucle

Usa un bucle for

Cuando conoces el contador o la colección que procesarás.

Usa un bucle while

Cuando la repetición depende de una condición que puede cambiar.

Verificación de seguridad: todo bucle necesita avanzar hacia su condición de salida o podría no terminar.
16 · Implementación

Haz explícito el trabajo repetido.

Repetición contada
for (int i = 0; i < 3; i++) {
  System.out.println(i);
}

Inicializar → verificar → cuerpo → actualizar.

Controlada por condición
int attempts = 0;
while (attempts < 3) {
  System.out.println(attempts);
  // La actualización acerca el final.
  attempts++;
}

La actualización evita un bucle infinito accidental.

Aplicación: ambos ejemplos imprimen 0, 1 y 2. Al llegar a 3, la condición es falsa y el cuerpo ya no se ejecuta. ++ suma una unidad.
Bucles · sigue el estado

La última comprobación también importa.

int suma = 0;
for (int i = 1; i <= 3; i++) {
  suma = suma + i;
}
System.out.println(suma);
Estado antes y después del cuerpo
ii ≤ 3suma al salir
1true1
2true3
3true6
4false6 · no entra
Practica: sustituye <= 3 por < 3. Predice cuántas iteraciones habrá y qué imprimirá antes de ejecutar.
17 · Aplicación

Junta las herramientas: una regla simple de compra.

double total = 125.0;
boolean member = true;
double shipping = 8.0;

if (total >= 100) {
  shipping = 0;
}
if (member) {
  total = total * 0.95;
}

total = total + shipping;
Sigue el estado

1. Inicio: total 125, shipping 8.

2. Se alcanza el umbral: el envío pasa a 0.

3. Se aplica la regla de miembro: el total pasa a 118.75.

4. Total final: 118.75.

Observa: las variables guardan estado; los operadores calculan; los condicionales eligen reglas.
18 · Mentalidad de depuración

La mayoría de errores iniciales son malentendidos que se vuelven visibles.

= vs ==

total = 100 asigna. total == 100 compara.

División entera

5 / 2 con enteros produce 2, no 2.5.

Bucles con límite incorrecto

Comprueba si incluyes el primer y último índice válido.

Comparar texto

Usa "PAID".equals(status) para contenido. Con objetos, == compara referencias, no el texto.

Hábito de depuración: predice el valor, ejecuta el código y compara el resultado. No adivines en silencio.

20 · Práctica

Ejercicio: construye una calculadora de tarifa de entrega.

Objetivo

Escribe un programa Java que calcule una tarifa de entrega según el total de la orden y la membresía.

Punto de partida

double total = 75.0;
boolean member = false;

Restricciones

Envío: 8 unidades; gratis si el total original es ≥ 100. Descuenta 5 al total si es miembro, sin bajar de 0. Luego suma el envío. Usa variables y condicionales.

Resultado esperado

Imprime el monto final y la regla aplicada. Prueba: 75 sin membresía → 83; 75 con membresía → 78; 100 sin membresía → 100.

Desafío opcional

Procesa tres totales de orden con un bucle e informa cuántos califican para envío gratis.

Prueba de éxito: cambia las entradas y verifica que cada camino se comporte correctamente.
Pide primero escribir las reglas en lenguaje natural y luego traducir una regla a la vez. No entregues la solución completa de inmediato.
